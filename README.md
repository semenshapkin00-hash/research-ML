# Скоринговая модель для микрофинансирования

Пет-проект: бинарная классификация для оценки кредитного риска на данных
[Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk).

Задача — предсказать вероятность просрочки по кредиту на основе анкеты заёмщика.
Сравниваются классические ML-алгоритмы, градиентные бустинги, нейронная сеть и stacking-ансамбль.

## Данные

| | |
|---|---|
| Источник | `application_train.csv`, Home Credit Default Risk (Kaggle) |
| Размер | 307 511 объектов, 120 признаков |
| Целевая переменная | `TARGET` — факт просрочки по платежам |
| Доля положительного класса | 8.07% |
| Метрика | ROC-AUC (задана условиями соревнования) |

Особенность задачи: слабый распределённый сигнал — линейные корреляции признаков
с целевой переменной не превышают 0.18 по модулю, пропуски присутствуют в 67 колонках из 120.

## Результаты

| Модель | ROC-AUC | Время обучения |
|---|---|---|
| **LightGBM** | **0.7661** | 19.8 мин |
| Stacking (LGBM + CatBoost + XGBoost) | 0.7658 | 14.0 мин |
| XGBoost | 0.7588 | 8.6 мин |
| CatBoost | 0.7534 | 8.7 мин |
| Random Forest | 0.7479 | 13.0 мин |
| Logistic Regression | 0.7474 | 1.3 мин |
| MLP (109-32-16-1) | 0.7432 | 0.6 мин |

Оценка на стратифицированной 5-фолдовой кросс-валидации (стекинг — на отложенной выборке 25%,
MLP — на валидационном сплите). Стандартное отклонение по фолдам: 0.0045–0.0049.

## Основные наблюдения

- **Сигнал преимущественно линеен.** Логистическая регрессия даёт 0.7474 за 77 секунд против
  0.7661 за 1188 секунд у LightGBM: +0.019 ROC-AUC при пятнадцатикратной разнице во времени обучения.
- **Бустинг обходит бэггинг** за счёт снижения смещения, а не дисперсии: Random Forest (0.7479)
  оказывается близок к линейной модели.
- **Стекинг подтвердил согласованность базовых моделей** — три бустинга на одних признаках
  дают скоррелированные ошибки, поэтому ансамбль совпадает с лучшей одиночной моделью.
- **Все 5 сконструированных признаков вошли в топ-20 по важности.** `CREDIT_ANNUITY_RATIO`
  занял 5-е место — выше, чем `AMT_ANNUITY` и `AMT_CREDIT`, из которых он построен.
- **Наиболее информативны внешние кредитные рейтинги** `EXT_SOURCE_1/2/3` — их важность
  втрое превышает важность следующего признака.

## Подход

**Предобработка.** Признаки разделены на три группы со своей стратегией заполнения пропусков:
бинарные (медиана), числовые (среднее), категориальные (мода + One-Hot). Вся предобработка
оформлена через `Pipeline` и `ColumnTransformer`, поэтому на кросс-валидации статистики
считаются отдельно на каждом train-фолде — утечки данных не возникает.

**Feature engineering.** Пять относительных признаков, отражающих логику кредитного скоринга:

| Признак | Формула |
|---|---|
| `CREDIT_INCOME_RATE` | `AMT_CREDIT / AMT_INCOME_TOTAL` |
| `ANNUITY_INCOME_RATE` | `AMT_ANNUITY / AMT_INCOME_TOTAL` |
| `CREDIT_ANNUITY_RATIO` | `AMT_CREDIT / AMT_ANNUITY` |
| `CREDIT_GOODS_RATIO` | `AMT_CREDIT / AMT_GOODS_PRICE` |
| `INCOME_PER_PERSON` | `AMT_INCOME_TOTAL / CNT_FAM_MEMBERS` |

**Валидация.** Стратифицированная 5-фолдовая кросс-валидация. Подбор гиперпараметров —
`GridSearchCV` (число отбираемых признаков) и `RandomizedSearchCV` (регуляризация Random Forest).
Отбор признаков — `SelectFromModel` поверх Random Forest.

**Нейронная сеть.** Полносвязная сеть `109 → 32 → 16 → 1` на PyTorch, ReLU, `Dropout(0.3)`,
`BCEWithLogitsLoss`, оптимизатор Adam. Ранняя остановка по `val_auc` с восстановлением весов
лучшей эпохи. Обучение на GPU Apple Silicon (`mps`).

## Запуск

```bash
pip install -r requirements.txt
jupyter lab end2end_scoring.ipynb
```

Датасет нужно скачать отдельно со
[страницы соревнования](https://www.kaggle.com/competitions/home-credit-default-risk/data)
и положить `application_train.csv` рядом с ноутбуком.

Полный прогон занимает около часа: основное время уходит на `GridSearchCV` для LightGBM (20 мин),
стекинг (14 мин) и `RandomizedSearchCV` для Random Forest (13 мин).
