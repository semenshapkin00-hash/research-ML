# Домашнее задание №1 — Mushroom Classification

## Датасет

[Mushroom Classification](https://www.kaggle.com/datasets/uciml/mushroom-classification) — 8124 строки, 22 категориальных признака, бинарная классификация (съедобный / ядовитый).

Выбран потому, что все признаки категориальные — это позволяет отдельно проверить гипотезы про кодирование (OHE), отбор признаков.

## Гипотезы

1. **OHE на все признаки не лучше SelectKBest**, потому что много лишних признаков.
2. **Удаление `veil-type` не изменит качества моделей**, потому что он константный.
3. **Признак `odor` в одиночку даст высокий accuracy (>90%)**, потому что он сильно коррелирует с target.
4. **RandomForest и дерево решений дадут схожее качество**, потому что признак `odor` даёт маленький разброс и ансамбль не нужен.
5. **Дерево без ограничения глубины даст качество не хуже дерева с ограничением**, потому что комбинация нескольких признаков может помочь дереву идеально определять классы.

## Результаты

| № | Гипотеза | Итог | Кратко |
|---|---|---|---|
| 1 | OHE vs SelectKBest | Частично | При k=5–10 SelectKBest уступает (0.974 / 0.985 против 1.000), но начиная с k≈50 качество совпадает с полным набором из 112 признаков |
| 2 | Удаление `veil-type` | Подтвердилась | ROC-AUC совпадает до 4-го знака на всех трёх моделях (LogReg, Tree, RF) |
| 3 | Только `odor` | Подтвердилась | accuracy = 0.985, ROC-AUC = 0.987 — значительно выше порога 90% |
| 4 | RF vs Tree | Подтвердилась | 1.0000 против 0.9998, разница 0.0002 — меньше std дерева |
| 5 | Глубина дерева | Подтвердилась | Переобучения не наблюдается, качество не падает с ростом глубины |

## Общий вывод

Задача близка к детерминированно разделимой: один признак `odor` решает её почти полностью, а полный набор признаков даёт ROC-AUC = 1.0.
