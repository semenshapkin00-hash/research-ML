## Подход: baseline → улучшения → финал

| Шаг | Что сделал 
Реализовал 5 моделей XGBoost, LGBMBoost, CatBoost, RandomForest, Lasso, в каждом отбор признаков по SelectfromModel LightGBM, k=50. В конце стекинг 5 моделей (LinearRegression, positive=True): итоговый скор:  **1.41927**

### 1. EDA

- Все 4992 признака числовые, пропусков в train нет
- Удалены константные признаки: 4992 → 4735
- Целевая переменная логарифмирована (`np.log1p`) — это одновременно и требование метрики (RMSLE = RMSE в лог-пространстве), и более удобная форма, которая не имеет выбросов в данном датасете.
- Корреляции признаков с таргетом слабые: максимум 0.27, нет ни одного доминирующего предиктора

### 2. Feature Engineering

Датасет разреженный (много нулей), поэтому построчные агрегаты несут информацию о «масштабе» клиента:

- `n_zeros` — количество нулей в строке
- `row_sum` — сумма по строке
- `row_mean` — среднее по строке
- `row_max` — максимум по строке

`row_mean` и `row_sum` попали в топ-10 по корреляции с таргетом (0.272 и 0.268) — то есть оказались сильнее большинства исходных признаков.

### 3. Отбор признаков

Везде выбирал по одной модели, max_features подобрал RandomizedSearchCV

### 4. Модели и ансамбль

Перед стекингом проверил корреляции предсказаний моделей (через `cross_val_predict`):

Три бустинга коррелируют между собой на 0.95+ — ансамбль из них одних даёт слабый прирост. RandomForest чуть разнообразнее (0.92), а Lasso — принципиально другая модель (0.50–0.58), потому что не ловит взаимодействия признаков.

## Что сработало

1. **Логарифмирование таргета** — самое влиятельное изменение. Не только по метрике, но и по скорости: обучение Lasso ускорилось с 141 сек до 0.39 сек.
2. **Добавление Lasso в ансамбль** — единственная модель с низкой корреляцией предсказаний, дала реальное разнообразие.
3. **Feature Engineering** - новые признаки показали высокую корреляцию с target, выше 90% исходных признаков 

## Что не сработало

1. **Стекинг трёх бустингов между собой** — корреляция предсказаний 0.95+, прироста почти нет. Проверка корреляций до стекинга сэкономила время.
2. **Дополнительные построчные признаки** (`row_std`, `row_median`, `row_skew`, `nonzero_mean`, `n_nonzero`) — CV изменился с 1.3402 до 1.3391, то есть в пределах шума. Зато `nonzero_mean` внёс NaN и сломал пайплайн, поэтому от расширенного FE отказался.
3. **Lasso как самостоятельная модель** — 1.6279, заметно хуже деревьев: линейная модель не справляется с этой задачей в одиночку.

## Что починил

1. **Утечка данных** раньше importance считалось по всей выборке и применялось в каждой модели, сейчас отбор параметров в пайплайне всех моделей.
2. **Отбор гиперпараметров** добавил  в SelectfromModel и в предсказывающих моделях.
3. **OOF предсказания для стекинга**

## Вывод

Проделанная работа над ошибками уменьшила скор на kaggle на 0.05, значит неточночти откорректированы верно.
